# Podlets WDTT (Windows PC Edition)

**Podlets WDTT** — полноценный клиент защищённого L3-туннеля для подключения к вашему VPS на Windows с обфускацией под медиа-трафик VK Calls.

Приложение собирается в **автономный файл `podlets-wdtt.exe`** и организует данные в портативной папке `resources/` рядом с программой:
- `resources/config.json` — конфигурация, профили и подписки.
- `resources/wintun.dll` — драйвер сетевого адаптера (самовосстанавливается при отсутствии).
- `resources/bypass_subnets.txt` — список подсетей и адресов для прямого доступа (обход VPN).

---

## Возможности

- **Системный VPN через Wintun (L3)**: создаёт высокоскоростной виртуальный сетевой адаптер `PodletsWDTT` через нативный Win32 IP Helper API (`winipcfg`) и направляет весь интернет-трафик ПК через защищённый туннель.
- **Единый автономный бинарник**: всё вшито внутрь `.exe` (драйвер Wintun, React+Tailwind интерфейс, Go-ядро). Никаких сторонних установщиков не требуется.
- **Портативность и самовосстановление**: если папка `resources/` или любой файл в ней удалены, программа автоматически воссоздаёт их при запуске.
- **Добавление профилей**: поддержка ссылок на подписки, импорт ключей/ссылок `podlets://`, `wdtt://` или `qwdtt://`, а также ручной ввод.
- **Подписки**: поддержка автозагрузки и обновления списков профилей по URL.
- **Интерактивная капча**: всплывающее окно прямо в интерфейсе с автоматическим решением и подтверждением («Я не робот»).
- **Исключения (Split Tunneling)**: настраиваемый список подсетей и IP-адресов, которые идут напрямую через физический шлюз (VK TURN-серверы и локальные сети защищены от зацикливания).
- **Живая статистика и логи**: график скорости отдачи/загрузки, пинг, количество активных потоков, терминал с цветными логами и фильтрацией.
- **Системный трей**: сворачивание в трей, контекстное меню с кнопками «Подключиться» и «Отключиться».

## Быстрый старт

1. Запустите файл `podlets-wdtt.exe` (расположен в `Podlets WDTT/podlets-wdtt.exe`).
2. При запуске Windows запросит подтверждение прав администратора (требуется для создания адаптера Wintun и управления системными маршрутами).
3. Добавьте сервер и нажмите «ПОДКЛЮЧИТЬ».

## Сборка из исходников

Требования:
- Go 1.25+
- Node.js & npm
- Wails CLI v2

Сборка оптимизированного релиза:

```powershell
cd Windows
wails build -ldflags "-s -w"
```

Готовый бинарник сохраняется в `podlets-wdtt-windows/build/bin/podlets-wdtt.exe`.

## Происхождение проекта и благодарности

**Podlets WDTT (Windows Edition)** является форком и десктопной адаптацией проекта [qWDTT](https://github.com/SpaceNeuroX/proxy-turn-vk-android) (автор *SpaceNeuroX*), который базируется на идеях оригинального [WDTT](https://github.com/amurcanov/proxy-turn-vk-android).

### Ключевые отличия и доработки Podlets WDTT:
- Разработано независимое десктопное приложение для Windows на базе **Wails v2 (Go + React + Tailwind CSS)**.
- Реализована полноценная сетевая маршрутизация уровня ядра Windows (L3 VPN) через официальный драйвер **Wintun** и библиотеку `winipcfg`.
- Портативная структура хранения конфигураций в каталоге `resources/` с автоматическим самовосстановлением при случайном удалении.
- Встроенный интерактивный блок решения капчи прямо в интерфейсе программы.
- Нативная интеграция с системным треем Windows (управление состоянием, быстрый Connect/Disconnect).
- Проведена глубокая оптимизация кодовой базы: вычищены неиспользуемые userspace-стеки, размер скомпилированного бинарника уменьшен до ~19 МБ.
